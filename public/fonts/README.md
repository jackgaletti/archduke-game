# Dela Gothic One

`dela-gothic-one-logo.ttf` is the official Dela Gothic One regular font, subset to the uppercase letters in ARCHDUKE through Google Fonts. It is self-hosted for the text logo. Copyright and SIL Open Font License terms are in `OFL.txt`.

Source: https://fonts.googleapis.com/css2?family=Dela+Gothic+One&display=swap&text=ARCHDUKE
License: https://github.com/google/fonts/blob/main/ofl/delagothicone/OFL.txt
Retrieved 2026-09-14.

`dela-gothic-one.ttf` is the complete regular 400 face from the same Google Fonts family, for game controls and names. CSS uses complementary Unicode ranges so the approved logo keeps its existing subset. Both files are covered by OFL.txt. Full source: https://fonts.googleapis.com/css2?family=Dela+Gothic+One&display=swap
