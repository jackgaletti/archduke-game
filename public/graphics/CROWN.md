# Supplied crown

`crown.png` is a byte-for-byte copy of the user's `~/Downloads/crown.png` (400×400 RGBA; visible alpha bounds 18,18–381,381). Its transparency and proportions are preserved.

The dominant solid gold is RGB **251, 180, 99**, hex **#FBB463**: 30,422 fully opaque pixels. Sampling excluded transparent/antialiased pixels and required a gold hue (R > G > B, each separated by more than 20), excluding dark outlines and pale highlights. This image has one solid qualifying gold color.

The CSS `--gold` token supplies the turn triangle, underline, caller name, called button and burst. The supplied crown itself appears beside the caller's name.
